# Blockchain Vehicle Registration System - Frontend

This is the frontend for the Blockchain Vehicle Registration System, a decentralized application for managing vehicle registrations.

## Tech Stack

-   **Next.js:** As the React framework.
-   **React:** For building the user interface.
-   **TypeScript:** For static typing.
-   **Tailwind CSS & Flowbite:** For UI styling and components.
-   **Web3.js:** For interacting with the Ethereum blockchain.
-   **TanStack Query:** For managing server state.

## Getting Started

To get the client running locally, follow these steps:

1.  **Prerequisites**
    -   [Node.js](https://nodejs.org/) (v24.10.0)
    -   The backend server must be running.
    -   Create a `.env` file from the `.env.example` and fill in the required environment variables.
    
2.  **Installation**
    ```bash
    npm install
    ```

3.  **Running the Development Server**
    ```bash
    npm run dev
    ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Scripts

-   `npm run dev`: Starts the development server with Turbopack.
-   `npm run build`: Builds the application for production.
-   `npm run start`: Starts a production server.
-   `npm run lint`: Runs the linter to check for code quality.
